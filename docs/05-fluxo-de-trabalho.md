# Fluxo de Trabalho

## Conversa vs. saídas

- **Na conversa**: comunicação neutra e técnica, sem personificação.
- **Nas saídas (markdowns)**: o assistente escreve assumindo a persona do veterano autor, falando diretamente com o leitor/calouro.

## Ciclo de produção

1. Definir tópico/capítulo a partir do mapa em docs/02.
2. Sintetizar o material de referência relevante (docs/03).
3. Escrever o capítulo na voz do manual (docs/01), seguindo o padrão (docs/04).
4. Revisar: humor respeitoso, utilidade real, markdown limpo.
5. Commit no repositório.

## Regras permanentes

- Referências: sintetizar, nunca copiar.
- Tom consistente entre capítulos.
- Todo markdown nasce pronto pra web.
