# Visão Geral do Projeto

## O que é

O **Manual do Bixo Ultimate** é um manual satírico e utilitário para calouros da Unicamp (campus FT/Limeira), escrito em markdown para servir de base da versão web.

## Objetivos

1. Preservar e atualizar o conhecimento dos manuais históricos da FT/Unicamp.
2. Entregar informação útil com humor: cada piada carrega um macete real.
3. Produzir markdown limpo e portável, pronto para renderização web.

## Escopo

- Serviços da universidade (RU, biblioteca, Intercampi, DAC, SAE, SAPPE etc.)
- Organizações estudantis (CAs, atléticas, empresas juniores, comissões)
- Sobrevivência acadêmica (aulas, provas, pesquisa, moradia, transporte)
- Cultura e calourada (trote solidário, gincana, festas)

## Referências base

PDFs históricos: Manual do Bixo 2013 (CAT/FT), Manual dos Bixos CDI 2024 e demais edições. Regra: sintetizar e reescrever, nunca copiar.
